# Bench photo and identification checklist

Use this whenever new hardware is added to either the generic WoTEx Lab or the
Tracker lab.

## Required photos

- [ ] front of board/device
- [ ] back of board/device
- [ ] product label
- [ ] PCB silkscreen/revision
- [ ] connector/pin labels
- [ ] power-supply label
- [ ] packaging model number when useful

## Required observations

- [ ] manufacturer/model
- [ ] PCB revision
- [ ] main IC marking
- [ ] supply voltage
- [ ] GPIO/logic voltage
- [ ] connector type
- [ ] firmware version
- [ ] USB identity from `lsusb` if applicable
- [ ] network identity/protocol documentation
- [ ] local-control path without mandatory cloud

## Current unresolved items

- exact actual Nano board/header state inside the boxes;
- Delock smart-plug model;
- blue USB serial/programmer chipset and logic voltage;
- green USB/ESP programmer exact model and logic voltage;
- Plexgear USB dongle exact function/model;
- small round USB dongle exact function/model;
- remaining bagged green boards/modules;
- Pi fan rated voltage and exact GPIO pins occupied;
- exact power-supply ratings;
- confirmation of available multimeter and logic analyzer.

Until identified, these items are excluded from pin-perfect wiring
instructions.
